# Issue tracker: PLAN.md

This repo does not use GitHub Issues. Open issues are one list in
[PLAN.md](../../PLAN.md), section **5. Open issues**.

- **Create an issue**: add a bullet to that list: a bold short name, then one or two lines.
  Longer details go in the matching topic doc (`docs/*.md`), linked from the bullet.
- **Close an issue**: remove the bullet (and its section in the topic doc) once done.
- No labels, no triage states.

## When a skill says "publish to the issue tracker"

Add a bullet to PLAN.md §5.

## When a skill says "fetch the relevant ticket"

Read PLAN.md §5 and any topic doc the bullet links to.
