# cf_display

Desk info display: Raspberry Pi + 720×720 screen, running a Processing 4 sketch.

See [PLAN.md](PLAN.md) for the architecture and build plan.

## Running on desktop

Requires Processing 4.5 or newer.

In VS Code: **Terminal → Run Task… → Run sketch** (or `Ctrl+Shift+B` / `Cmd+Shift+B`).

From a terminal:

- Windows: `& "C:\Program Files\Processing\Processing.exe" cli --sketch="<repo path>" --run`
- macOS: `/Applications/Processing.app/Contents/MacOS/Processing cli --sketch="<repo path>" --run`
